## English

Senior engineer, ~10 years, working at Staff scope: ADRs, platform governance
and standards. Most of that time on distributed backends and event-driven
systems for fintech products used by millions.

Today I work on AI-driven engineering — defining how coding agents, skills, MCP
and spec-driven development get adopted across the SDLC — and own architectural
definitions for a multi-product financial platform.

**Work**

- **Distributed backends** — microservices on AWS with SQS and Kafka, async
  integration across mobile, web and external APIs. DynamoDB, PostgreSQL.
- **Event-driven architecture** — services built on messaging and async
  contracts instead of synchronous call chains.
- **Frontend at scale** — Module Federation, micro frontends, React Native.
- **Observability and delivery** — trace correlation, RED/USE metrics,
  OpenTelemetry, CI/CD. Led refactors that raised coverage and cut incidents.
- **Governance** — approval and push rules, protected branches, secret
  detection, RFC/ADR templates, boilerplates pre-gated with lint and tests.
- **Applied AI** — agent orchestration, spec-driven frameworks, custom Agent
  Skills and hooks, MCP. Studying LLM observability and vector search.

I don't just use AI to write code. I build the harness, the deterministic gates
and the verification layers that make agents trustworthy in production.
Engineering fundamentals are the durable layer of control over any AI
trajectory.

**Side projects**

- **BMAD + Claude Code harness** — bootstrap installer, custom hooks, Agent
  Skills, one config unified by symlink across CLI, Desktop and VS Code.
- **TCG Experts Commerce** — trading card platform: card scanning, inventory,
  buying and selling. Built with a team.
- **Enjoy the Process** — productivity app on Vite, React, Supabase: habit
  tracking, neuroscience-informed insights, financial dashboards.
- **Obsidian second brain** — git-versioned, YAML frontmatter as pipeline
  contract, planned RAG over Qdrant with wikilinks as graph edges.

**Teaching and talks** — Gama Academy: JavaScript from intro to
advanced, DevOps, testing and QA, including a class for visually impaired
students. Spoken several times at ETEC. Translated parts of the React docs into
Brazilian Portuguese.

Finishing an MBA in Software Architecture at Full Cycle. Systems Analysis and
Development at FIAP. IT technician at ETEC.
